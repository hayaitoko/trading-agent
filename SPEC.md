# Spec

Goal: trading-agent Build a Python trading-agent framework that supports BOTH crypto (Binance + Coinbase via ccxt) AND US equities (Alpaca, paper first then live). Two operating modes, switchable globally and per-asset via config: - AUTONOMOUS: agent executes trades on its own. Hard kill switch (single env var or file flag). Per-strategy circuit breakers: max-daily-loss, max-position-size, max-trades-per-hour, max-open-positions. - APPROVAL: agent emits proposed trades to a queue; pushes them to me via the existing artoo Telegram bot. I /approve or /reject each one before execution. Approval timeout cancels the proposal. Core abstractions: - BrokerAdapter — uniform interface over ccxt (crypto) and alpaca-py (equities). Methods: get_balance, get_positions, place_order, cancel_order, get_quote. - DataFeed — market data ingestion. Websocket for crypto, polling for stocks. Pushes bars + ticks to strategies via in-process pub/sub. - Strategy — pluggable. Each declares its data needs (symbols, timeframe), params (loaded from a TOML per strategy), and emits Signal objects (buy/sell/close + size + reason). - SignalRouter — Signal → either direct broker.place_order (autonomous) OR approval queue (approval). - RiskManager — circuit breakers + position sizing + kill switch. Sits between SignalRouter and broker. - PaperBroker — in-memory broker for backtest + dry-run. Same BrokerAdapter interface. Persistence: SQLite. Tables: trades, signals, positions, audit_log. WAL mode (lifted from artoo's own SQLite setup). Config: per-strategy TOML files. Top-level YAML for global settings (kill switch, default mode, broker credentials via env-var refs). Logging: structured JSON to stdout; activity.py-style per-day JSONL file in data/. Tests required: BrokerAdapter contract tests (same suite runs against PaperBroker and real adapters), SignalRouter dispatch logic, RiskManager circuit breaker logic. Aim for ≥80% line coverage on those three modules. Out of scope for this build: deployment infra, Docker, web UI, strategy R&D. Use ONE placeholder strategy (simple mean-reversion: 20-period SMA, buy on -2σ, exit on touch) just to prove the framework end-to-end. Repo layout: src-style Python package, pyproject.toml, pytest, ruff. Python 3.12. heres the current code : https://github.com/hayaitoko/trading-agent
